The document shows the description of the vision and goals of the project.

* The product is a tool which aims to support the user in keeping a balance over all the aspects of their life.
* It is an analog todo list and habit tracker which allows the user to enter the values of how much progress they made on a task or a habit.
* Different tasks and habits belong to different categories.
* Examples of categories:
    * Work
    * Personal
    * Health
    * Family
    * Friends
    * Finances
    * Fun
* Examples of one off tasks:
    * Apply for the job at company X
    * Browse laptops to buy one
    * Edit subscription to the newsletter
* Examples of habits:
    * Read 10 pages of a book every day
    * Exercise 30 minutes every day
    * Meditate 10 minutes every day
    * Drink 2 liters of water every day
    * Go to bed at 11pm every day
* The difference in the app is that all tasks and habits are numerical values
* For one off tasks the user can do a few minutes of work and log the progress in comments so that he can continue from where he left off.
* If the user didn't do anything a number of days dormancy is shown beside the task to show how long has it been procrastinated.
* Same for habits, they are not just done or not done, but can be done partially.
* All habits should be constructed as levels of completion.
* If the goal amount is to exercise 30 minutes daily, then the base level would be 2 minutes, the good level would be 30 minutes and the excellent(exceeed level) would be 60 minutes.
* Ticking off a habit should be done as easily as binary ones. Meaning that there should be a one click button to finish the habit at the current level.
* The other option would be to enter the amount of units done.
* The longer entry mode as well should show logs of comments made and when they were made. For tasks which take several days or habits which build on each other, it is useful to know where to start to tick off the habit.
* For example when the habit isreading 10 pages of a book, we start from the page we stopped at the day before which should have been entered in the comments.
