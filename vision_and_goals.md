The document shows the description of the vision and goals of the project.

* The product is a tool which aims to support the user in keeping a balance over all the aspects of their life.
* It is an analog todo list and habit tracker which allows the user to enter the values of how much progress they made on a task or a habit.
* Different tasks and habits belong to different categories.
* Examples of categories:
    * Work
    * Personal
    * Health
    * Family
    * Friends
    * Finances
    * Fun
* Examples of one off tasks:
    * Apply for the job at company X
    * Browse laptops to buy one
    * Edit subscription to the newsletter
* Examples of habits:
    * Read 10 pages of a book every day
    * Exercise 30 minutes every day
    * Meditate 10 minutes every day
    * Drink 2 liters of water every day
    * Go to bed at 11pm every day
* The difference in the app is that all tasks and habits are numerical values
* For one off tasks the user can do a few minutes of work and log the progress in comments so that he can continue from where he left off.
* If the user didn't do anything a number of days dormancy is shown beside the task to show how long has it been procrastinated.
* Same for habits, they are not just done or not done, but can be done partially.
* All habits should be constructed as levels of completion.
* If the goal amount is to exercise 30 minutes daily, then the base level would be 2 minutes, the good level would be 30 minutes and the excellent(exceeed level) would be 60 minutes.
* Ticking off a habit should be done as easily as binary ones. Meaning that there should be a one click button to finish the habit at the current level.
* The other option would be to enter the amount of units done.
* The longer entry mode as well should show logs of comments made and when they were made. For tasks which take several days or habits which build on each other, it is useful to know where to start to tick off the habit.
* For example when the habit is reading 10 pages of a book, we start from the page we stopped at the day before which should have been entered in the comments.
* The app should also have a quick way to add new tasks and habits. If their category is not present, it should be created easily and if it is not using the standard levels (Basic, Good, Excellent) it should be added to the list of levels combinations.
* We should be able to add definitions for amounts of units per level. And unit used per task or level.
* For example a habit should have a standard unit chosen by the user on creation but when creating levels the user can choose a different unit other than the standard one for the level,
* For example if the habit is about reading pages of a book, the good level would be set to 10 pages, the basic level would be recommended to be 2 pages and the excellent level would be 20 pages. the other two levels are either recommended by the app or fully manually entered by the user. However the user can choose to have the excellent level to be a chapter, which is a different unit than pages.

The information I want to see and how I think it should be presented:
* The streaks of the tasks and habits: how many days in a row the user has done the task or habit and how many days since the user did the last action (dormancy)
* The above aims to help me prioritise which tasks to start with through seeing the tasks with longest streaks first to keep the momentum and build up the habit.
* The dormancy is useful to put pressure on tasks procrastinated for a long time to get started on them even if for a small action.
* The tasks should be organised in a way not to overwhelm the user with too many tasks at once. meaning that the next recommended task or two should be shown while the others are not all shown so that the user can focus on the next task.
* The next task should be the basic level of the habit with the longest streak.
* If all basic levels are done, meaning that there is no dormancy, then the user is shown tasks to get to the next level
* The user should have the ability to easily see the full list of tasks though in case the recommendations are not what they want to do.
* The buttons and fields to get levels done or parts of them should be easy to finish a level with one click or add some amount of units.
* it should be easy to expand more and more comments to be able to see the history of the task and the progress made and stopping points.
* I should be able to see for each given day what is the log of tasks and habits done and what is the percentage of tasks and habits done in each level and trying to reach the goals of 100%
